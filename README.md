# 🚀 Overview

Autonomous Data Science Co-Pilot is an AI-powered analytics assistant capable of performing complete data analysis without writing code manually.

Simply upload a dataset and ask questions in plain English.

The AI agent automatically:

- Generates Python code
- Executes it securely
- Detects runtime errors
- Repairs broken code using Retrieval-Augmented Generation (RAG)
- Generates professional charts
- Produces business insights

It behaves like an autonomous junior data analyst capable of understanding datasets and producing visual reports.

# ✨ Key Features

## 🤖 AI Code Generation

Generate complete Python analysis code from natural language.

---

## 📈 Interactive Visualizations

Automatically creates

- Bar Charts
- Line Charts
- Pie Charts
- Scatter Plots
- Histograms
- Heatmaps
- Boxplots

using Matplotlib and Seaborn.

---

## 🧠 Natural Language Queries

Examples

- Show revenue by region

- Compare monthly sales

- Top 5 products

- Sales trend over time

- Missing values

- Correlation heatmap

---

## ⚡ Autonomous Self-Healing Engine

Instead of stopping after an error,

the AI

- detects the exception
- searches official documentation
- retrieves relevant information
- rewrites the broken code
- executes again

until the analysis succeeds.

---

## 🔍 Retrieval Augmented Generation (RAG)

Official documentation sources

- Python Docs
- Pandas Docs

Only trusted documentation is used to repair generated code.

---

## 📂 Supported Dataset Formats

- CSV
- XLSX
- XLS
- JSON
